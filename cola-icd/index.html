Overview

More than half of the ICD codes in MIMIC appear fewer than ten times in training. Those rare codes are hard to learn, and clinical notes rarely describe them in the wording of the official ICD description: a note says "former smoker" where the code says "personal history of tobacco use".

CoLa-ICD gives each code a richer, clinically worded representation and ties it to the exact span of the note that supports it. It combines UMLS synonyms with LLM-generated clinical terms, shares signal between related codes through a co-occurrence graph, lets each term look for its own evidence in the note, and uses contrastive learning with hard negatives so that look-alike codes stay apart.

Method

Knowledge injection

Each code gets a list of terms: its official description, UMLS synonyms, and Gemini-generated abbreviations and clinical expressions that match how notes are actually written.

Co-occurrence graph

A PPMI-weighted graph of codes that appear together in training, processed by a two-layer GCN, lets rare codes borrow signal from clinically related ones.

Multi-head term attention

Every term queries the long note separately, so one head can catch an abbreviation while another finds the formal diagnosis phrase.

Label-aware contrastive learning

The evidence for a code is pulled towards that code and pushed away from similar but wrong codes, chosen as hard negatives.

The text encoder is SapBERT; long discharge summaries are split into chunks and encoded without truncation.
